# 🎓 BacPlanner - Tunisian Bac AI Assistant & Planner

> **BacPlanner** is a desktop application designed specifically to help Tunisian Baccalaureate students organize their schedules, track their study status, and interact with an intelligent AI mentor! 🇹🇳💪

---

## 🔑 How to Set Up Your API Key

To power the AI assistant within the application, you will need your own Gemini API key:

1. **Get your API Key:**
   * Head over to [Google AI Studio](https://aistudio.google.com/) 🌐.
   * Generate your free API key (`Create API Key`).

2. **Manual Input:**
   * When you run the application or tools (`plan.py` / `status.py`) for the first time, you can input your API key manually.
   * The app will handle and save it locally so you are ready to go!
