# BacPlanner

A desktop study and revision planner designed for Tunisian Bac Informatique students.

## Description

BacPlanner is a Python-based desktop application that helps students organize their Bac Informatique revision in one place.

The application provides a structured database of subjects and lessons and allows students to track their revision status and academic progress.

## Features

- 📚 Bac Informatique subjects and lessons
- 📝 Revision tracking
- 🔴 To Do
- 🟡 In Progress
- 🟢 Completed
- 🔵 Review
- 💾 SQLite local database
- 🖥️ PyQt5 graphical interface
- 📊 Grade and progress features planned

## Technologies

- Python
- PyQt5
- SQLite
- Qt Designer
